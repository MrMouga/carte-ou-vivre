# Carte où vivre

Une carte de France qui colore les villes selon tes critères à toi (l'adresse de tes proches, la mer, la montagne, les prix, l'emploi) pour les trentenaires qui quittent une grande ville et veulent être sûrs d'aller visiter les bonnes.
