## Décisions prises à la place de Vincent
- Décision : **le délai de 10 s court depuis la première demande**, nouvel essai compris (une seule minuterie pour les deux demandes) — pourquoi : H187 dit « après une seconde erreur ou 10 s sans réponse » ; c'est la lecture la plus courte pour la personne qui attend — coût si c'est faux : une ligne de `chargerCodesPostaux` (`src/domain/recherche.ts`).
- Décision : **l'état des codes vit dans `App`**, pas dans le champ : fermer la recherche puis la rouvrir ne redemande pas des codes déjà arrivés, et une demande en cours n'est pas doublée — pourquoi : « une demande » de H187 ; le champ est démonté à chaque « Annuler » — coût si c'est faux : aucun pour l'utilisateur.
- Décision : une **réponse arrivée après les 10 s est ignorée** ; la prochaine prise de focus redemande — pourquoi : une fois « indisponibles » affiché, le message ne change pas sous les yeux sans geste ; H187 dit « nouvel essai à la prochaine prise de focus » — coût si c'est faux : garder la réponse tardive (quelques lignes).
- Décision (décidé par Claude) : dans une suggestion par code, **le code est en gris** (`muted-foreground`, chiffres à chasse fixe) et le nom en gras, comme le prototype C (capture F-bureau-code-complet) ; le nom accessible reste exactement « 33991 · Grandeville (33) » (plan) — coût si c'est faux : une classe.
