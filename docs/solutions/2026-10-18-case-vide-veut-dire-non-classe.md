# Une case vide dans une donnée officielle : chercher la règle qui l'a laissée vide avant de l'appeler « sans »
Étiquettes : data, spec · Tranche : mairies · Source : /spec mairies, [relecture.md](../specs/2026-10-18-mairies/relecture.md) (« Décisions cachées »)

**Problème** — Dans les résultats des municipales 2026, 91 % des listes gagnantes n'ont pas de nuance politique. La spec en a fait une pastille « Sans étiquette », comme si ces listes s'étaient dites sans bord.
**Symptômes** — Le relecteur l'a relevé ; mesuré ensuite : les 31 508 mairies sans nuance sont toutes dans des communes de moins de 3 500 habitants. Le ministère ne nuance que les communes de 3 500 habitants et plus et les chefs-lieux d'arrondissement (circulaire du 2 février 2026). Un village dont le maire est connu comme LR aurait été affiché « sans étiquette ».
**Ce qui n'a pas marché** — Compter les valeurs vides sans les croiser avec la population ; lire la presse pour le seuil sans en tirer le sens de la case vide. Un second compte rapide (« 25 communes sans sièges ») était faux, dit à Vincent puis corrigé.
**Ce qui a marché** — Croiser la case vide avec la taille de la commune (`< 3 500` : 31 508 sans, 15 avec ; `≥ 3 500` : 0 sans). Puis D8 : la pastille garde le mot de Vincent, la fiche précise « (moins de 3 500 habitants) ». Pour le rattachement des nuances aux blocs : la décision du Conseil d'État (PDF lu avec `pdftotext`) plutôt qu'un regroupement fait par nous.
**Prévention** — Règle de jugement : avant de nommer une valeur manquante dans une spec, chercher la règle de la source qui la produit (un seuil, un champ non obligatoire, un millésime), puis la croiser avec une autre colonne (taille, date, département). Dire le résultat dans le libellé visible si le sens change. Refaire une seconde fois un compte avant de l'annoncer.
